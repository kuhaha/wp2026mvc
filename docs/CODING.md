## コーディング規約

1. **変数名**は、キャメルケース(`$userName`)やスネークケースのいずれかに統一する。スネークケースでは、単語をアンダースコアで区切り、すべて小文字にする。例：`$user_name`。変数名には、型を明示することが推奨される（`int, float,string, bool, array, object`）。
2. **定数名**は 大文字＋アンダースコア（例：`MAX_COUNT`）
3. **クラス名**は パスカルケースを採用し、各単語の先頭を大文字にし、単語を連結する。例：`UserProfile`
4. **メソッド名**は キャメルケースとして、最初の単語は小文字で始まり、以降の単語の先頭を大文字にする。例：`getUserName()`
5. **制御文**（`if`, `for`等）では、キーワードの後にスペースを1つ入れる
6. クラスやメソッドの**開き波括弧** { は次の行に記述する。それ以外の開き波括弧は 改行せず同じ行に記述する。**閉じ波括弧** } は 新しい行にする
7. ファイルの最後までPHPコードが続く場合は、閉じタグ`?>`を書かない
